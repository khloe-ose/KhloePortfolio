TaskMo!

TaskMo! is a full-stack project and task management system for teams. It includes JWT authentication, role-based access control, project CRUD, task assignment, Kanban tracking, task comments, activity logs, dashboard analytics, a responsive React UI, and MySQL schema and seed files.

Tech Stack

Tools and Frameworks

  • Frontend: React.js with Vite
  • Styling: Tailwind CSS
  • Backend: Node.js with Express.js
  • Database: MySQL
  • Authentication: JWT
  • Password hashing: bcrypt
  • Charts: Recharts
  • Icons: Lucide React

Features

Main Capabilities

  • User registration and login
  • JWT authentication and protected routes
  • Role-based access: Admin, Project Manager, Team Member
  • Admin user management
  • Project creation, editing, deletion, and details
  • Task creation, editing, assignment, due dates, priority, and status tracking
  • Kanban board with To Do, In Progress, and Completed columns
  • Task comments
  • Search and filters by status, priority, assignee, due date, and keyword
  • Dashboard cards and charts for tasks, priorities, statuses, overdue work, and project completion
  • Recent activity log
  • Loading, empty, success, error, validation, and delete confirmation states
  • Responsive layout for desktop, tablet, and mobile

Role Permissions

Access Levels

  • Admin: manage all users, create/edit/delete projects, view all tasks and analytics.
  • Project Manager: create projects, assign tasks, update task status, and view project analytics.
  • Team Member: view assigned tasks, update task status, and add comments.

Local Setup

Environment Variables

Create server/.env:

PORT=5001
NODE_ENV=development
CLIENT_URL=http://localhost:5173

DB_HOST=127.0.0.1
DB_PORT=3307
DB_USER=root
DB_PASSWORD=
DB_NAME=taskflow

JWT_SECRET=replace_this_with_a_long_random_secret
JWT_EXPIRES_IN=7d

Create client/.env:

VITE_API_URL=http://localhost:5001/api

Run Locally

Install, Database, and Start Commands

Install dependencies from the project root:

npm --prefix server install
npm --prefix client install

Create the MySQL database and seed data:

mysql --protocol=TCP -h 127.0.0.1 -P 3307 -u root < server/database/schema.sql
mysql --protocol=TCP -h 127.0.0.1 -P 3307 -u root taskflow < server/database/seed.sql

Start the backend and frontend in separate terminals:

npm --prefix server run dev
npm --prefix client run dev -- --host localhost

Open http://localhost:5173. The API health check is available at http://localhost:5001/api/health.
