StockIt

StockIt is a full-stack inventory and asset management system for offices, schools, and organizations. It supports asset tracking, QR-based asset identification, category and location management, borrow requests, returns, reports, audit logs, and role-based access.

Project Overview

Purpose and Scope

The system centralizes organizational inventory records and borrowing workflows. It gives administrators and inventory managers a structured way to track assets, maintain setup data, approve or reject requests, monitor returns, and review activity through dashboards, reports, and audit logs.

Features

Main Capabilities

  • JWT authentication with bcrypt password hashing
  • Public staff registration and secure login
  • Role-based access for Admin, Inventory Manager, and Staff
  • Asset catalog with category, location, quantity, status, condition, and QR code fields
  • Asset add, edit, delete, detail, search, and filtering workflows
  • Generated QR codes for existing and newly created assets
  • Borrow request approval, rejection, return, and overdue handling
  • Category and location management
  • User management for admins
  • Audit logs for authentication, CRUD actions, approvals, and returns
  • Dashboard analytics for assets, availability, overdue returns, categories, conditions, and monthly activity
  • Admin reports with print and CSV export

User Roles

Access Levels

  • Admin: manages users, views inventory records, reviews audit logs, generates reports, and maintains setup data.
  • Inventory Manager: adds, edits, and deletes assets; approves or rejects borrow requests; marks returns; and manages categories and locations.
  • Staff: views available assets, submits borrow requests, returns borrowed assets, and reviews personal borrow history.

Tech Stack

Tools and Frameworks

  • Frontend: React.js with Vite
  • Routing: React Router
  • Styling: Tailwind CSS
  • API client: Axios
  • Backend: Node.js with Express.js
  • Database: MySQL with mysql2
  • Authentication: JWT
  • Password hashing: bcryptjs
  • Validation: Express Validator
  • QR codes: qrcode
  • Charts: Recharts
  • Icons: Lucide React

Local Setup

Run Locally

Create environment files for the server and client, seed MySQL, then start both apps.

cd server
npm install
npm run dev

cd ../client
npm install
npm run dev

Default URLs are http://localhost:5173 for the frontend and http://localhost:5000/api for the API, unless local ports are adjusted.
