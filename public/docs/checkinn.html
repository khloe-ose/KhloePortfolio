CheckInn

CheckInn is a full-stack event registration and QR attendance management system for student organizations, workshops, and conferences. It supports organizer authentication, event management, public registration, participant QR codes, attendance check-in, reports, and certificate generation.

Project Overview

Purpose and Scope

The system helps event organizers manage the full event attendance workflow: creating an event, publishing a registration page, collecting participant records, issuing QR-based attendance credentials, checking participants in, and reviewing attendance results through dashboards and exports.

Features

Main Capabilities

  • Organizer and admin registration/login with JWT authentication
  • Role-based protected dashboard routes
  • Event create, read, update, and delete workflows
  • Draft, published, completed, and cancelled event statuses
  • Public mobile-friendly participant registration form
  • Stored QR code data for registered participants
  • QR attendance check-in and manual check-in
  • Participant search and attended/not attended filters
  • CSV attendance export
  • PDF certificate generation for attended participants
  • Dashboard cards and charts for registrations, attendees, attendance rate, and popular events
  • Admin user management

User Roles

Access Levels

  • Admin: manages platform users, reviews events and analytics, and oversees organizer accounts.
  • Organizer: creates events, manages participant registrations, checks attendance, exports reports, and generates certificates.
  • Participant: registers through the public event form and uses the generated QR credential for attendance.

Tech Stack

Tools and Frameworks

  • Frontend: React.js with Vite
  • Styling: Tailwind CSS
  • Backend: Node.js with Express.js
  • Database: MySQL
  • Authentication: JWT
  • Password hashing: bcrypt
  • QR codes: qrcode
  • PDF generation: pdfkit
  • Charts: Recharts
  • Icons: Lucide React

Local Setup

Run Locally

The project includes helper scripts for a local MySQL-backed deployment.

npm run install:all
npm run local:start
npm run local:status

Default URLs are http://localhost:5173 for the frontend and http://localhost:5001/api for the API.
